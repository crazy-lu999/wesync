# 我们的小本本 — 夫妻共享待办小程序

夫妻两人共享一个待办清单：一方添加/勾选/删除，另一方实时可见。

- 后端：**微信云开发**（免服务器、免域名备案）
- 配对：**6 位邀请码**（A 创建家庭 → 把码发给 B → B 输入码加入）
- 同步：读写均走云函数，列表**每 5 秒自动轮询**，双人改动几秒内可见
- 稳定：数据访问只经服务端（不带客户端安全规则），逻辑简单、不踩规则坑

## 目录结构

```
shared-todo/
├── app.js / app.json / app.wxss      # 入口、配置、全局样式
├── project.config.json               # appid + 云环境配置
├── utils/
│   ├── db.js                         # 云函数封装 + todos 增删改查 + 轮询拉取
│   └── format.js                     # 时间格式化
├── pages/
│   ├── index/                        # 列表页/引导页合一，每 5 秒轮询同步
│   ├── create/                       # 创建家庭，生成邀请码
│   ├── join/                         # 凭邀请码加入
│   └── me/                           # 家庭信息、成员、退出
└── cloudfunctions/
    ├── createFamily/                 # 建家庭 + 生成唯一邀请码
    ├── joinFamily/                   # 凭码加入（满员/码错校验）
    ├── getMyFamily/                  # 查当前用户家庭
    ├── leaveFamily/                  # 退出（最后一人离开则清理数据）
    ├── todoOps/                      # 待办增删改（服务端写，带成员列表）
    └── getMyTodos/                   # 待办读取（服务端读 + 5 秒轮询）
```

## 首次使用配置（5 步）

### 1. 填 AppID 和云环境 ID
- 微信开发者工具导入 `shared-todo` 目录 → 项目设置里填 **AppID**。
- 点工具左上角「云开发」→ 开通/选择环境 → 记下**环境 ID**。
- 把环境 ID 填到 `app.js` 里的 `env: 'your-env-id'`。
- 把 AppID 填到 `project.config.json` 的 `"appid"`。

### 2. 建数据库集合
云开发控制台 → 数据库 → 新建两个集合：`families`、`todos`。
数据访问全部走云函数（服务端权限），**无需配置安全规则**，保持集合默认权限即可。

### 3. 部署云函数
在开发者工具左侧 `cloudfunctions` 目录下，**右键每个云函数文件夹** →
「上传并部署：云端安装依赖（不上传 node_modules）」。共 6 个：
`createFamily`、`joinFamily`、`getMyFamily`、`leaveFamily`、`todoOps`、`getMyTodos`。

### 4. 预览
点「预览」生成二维码，微信扫码在手机上打开。

### 5. 模拟双人测试
单人没法验证「双人同步」。两个微信号测试方法：
- 用你的微信 + 家人的微信分别扫码进入。
- 或在开发者工具里用「真机调试」+ 另一部手机分别登录不同微信号。

## 使用流程

1. **A**：打开小程序 →「创建家庭」→ 填昵称 → 得到 6 位邀请码 → 复制发给 B。
2. **B**：打开小程序 →「我有邀请码，加入」→ 输入码 + 昵称 → 进入共享清单。
3. 任一方添加/勾选/删除待办，对方列表**约 5 秒内**自动刷新出现。

## 验证清单

- [ ] 创建家庭 → 拿到 6 位邀请码
- [ ] A 添加待办，B 端**约 5 秒内**自动出现
- [ ] A 勾选完成，B 端该条划线
- [ ] A 长按删除，B 端该条消失
- [ ] 错误邀请码提示「邀请码不存在」
- [ ] 第三个号加入提示「家庭已满员」
- [ ] 退出家庭后回引导页，对方仍正常

## 技术要点

- **轮询同步**：首页每 5 秒调用 `getMyTodos` 云函数拉取一遍，双人改动几秒内可见；入口用 `onShow`/`onHide` 启停定时器，不常驻耗资源。
- **openid 信任**：创建/加入/查询/退出/待办读写全走云函数，openid 来自 `wx.getWXContext()`，客户端无法伪造。
- **服务端读写**：`todoOps`（增删改 + 写入成员列表）、`getMyTodos`（读）都是云函数，用服务端权限直连 `wx-server-sdk`，**不依赖客户端安全规则**，避免在控制台 UI 上配置权限时的坑。
- **邀请码唯一性**：生成后查 `count()`，重复则重生成，最多重试 20 次。
- **乐观更新**：勾选先改本地 UI 再写库，失败回滚，体验流畅。
